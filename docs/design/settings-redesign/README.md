# Settings redesign

Design assets for the Settings screen redesign. Editable canvas: https://claude.ai/code/artifact/9609ab7b-03d0-49b4-be60-4ac4cf98796c

- `after-*.png` are the proposed pages at 1440 wide, Graphite mode.
- `before/` are captures of the current build, taken from the running app on mock data.
- `before-after-*.png` are side-by-side composites.
- `system.png` is the component and rule sheet; `icon-set.png` compares icon libraries at rail size.
- `source/canvas/*.dc.html` are the mockups as standalone HTML. Open any of them in a browser.
- `source/build.mjs` generates the artboards from one shared stylesheet; `source/logos/exact.mjs` holds the exact Cursor and OpenCode marks as SVG, `source/logos/*.svg` the OpenAI and Claude marks.
