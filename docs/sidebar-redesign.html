What actually changes

  • One line per chat. The OpenCode · opencode-go/qwen3.7-plus subtitle on every row is the main source of noise — it moves to the tooltip and to the active row only.
  • Day headers. Today / Yesterday / Aug 17, sticky while scrolling, from startedAt.
  • 28px rows, 6px radius. ~22 chats visible instead of ~11; the 12px pill radius stops looking bulbous at row scale.
  • Projects above history. Structure is short and stable, history is long — so the long list goes last and never pushes projects off screen.

Type scale: 7 styles → 4

  • 14px semibold — wordmark only.
  • 13px — every row title, new chat, project name.
  • 11px — group and section labels, worker text. No more 0.16em uppercase, no gradient rule.
  • 10px mono — counts, timestamps, branch. Numbers only.
  • Gone: 8px / 9px / 9.5px worker text, 10px row subtitles, 12px footer.

Grouping & filter

  • Group by Date · Agent · Status · Name, from the ⇅ button on the history header, persisted in localStorage.
  • Filter matches title, harness and model, and hits inside projects auto-expand.
  • Show more caps a group at 12 rows so one busy day can't bury the rest.

Status, quieter

  • Today every row carries a dot, so 38 grey dots read as decoration. Idle drops to 30% opacity; only working / waiting / failed / ready keep full ink.
  • Active row = bg-accent + medium weight. The card fill, border and inset ring go away.
  • Workers collapse to a 26px strip with a foldable body — same information, a quarter of the chrome.
