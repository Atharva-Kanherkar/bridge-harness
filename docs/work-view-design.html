What flipping the pill does

Code is work inside a project, so its right side is a conversation. Work is everything that is not in a project, and the most useful thing to put there is what needs you — so the board is what you land on, and a chat is one click below it. Needs you is a real row in the rail, so going back to the board after opening a chat is the same gesture as switching chats.

Keyboard and screen readers

The pill is two radio buttons in one group, so left/right moves between Work and Code and the change is announced as a selection, not a navigation.

Each row is one tab stop, then its action. The row itself is not a button — only the action is — so nothing is clickable but unmarked.

Focus returns where it came from. Answering an approval opens the session; coming back lands focus on the row that replaced it, or the heading if the board emptied.

Names read without colour. “Blocking, completion check: cargo-test failed on Kyoto, seen just now. Review check.” Severity, source and freshness are all words in the accessible name.

Reduced motion. The only motion is a row leaving when a fact resolves; under prefers-reduced-motion it is removed without the collapse.
