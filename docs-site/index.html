What is Bridge

Bridge is a macOS desktop app that runs Codex, Claude Code, and OpenCode against isolated Git worktrees — one interface for supervising multiple coding agents, backed by a policy engine that decides what any of them are allowed to touch.

Three hierarchies, kept separate

The recurring design bug in agent tooling is conflating three things that only look alike: where files live, who's allowed to act, and what was said. Bridge keeps them as three distinct trees — see Three hierarchies for the full picture.

Workspace tree

Repo → task worktree → worker worktree. Every agent gets its own isolated checkout.

Agent tree

Orchestrator → policy-authorized workers. Delegation is a permission, not a suggestion.

Conversation tree

Immutable forest entries → the active branch. Append-only, forkable, never rewritten.

Forking a conversation does not undo filesystem changes. Ending a session does not discard a worktree. Each tree is managed on its own terms.

What's running underneath

A Rust workspace sits under a thin Tauri shell. bridged owns the data directory and speaks newline-delimited JSON-RPC over a Unix socket — the desktop app is just one client of it. See Protocol / RPC for the wire format.

Everything Bridge does today

Multi-agent sessions

Run Codex, Claude Code, and OpenCode side by side against the same repo.

Git worktree isolation

Every task and every worker gets its own checkout. Nothing collides.

Policy & approvals

One engine gates capability tier, write scope, concurrency, depth, and budget.

Session forest

Append-only history with immutable entries and verified checkpoint compaction.

Memory & learning

A pinned account ledger plus a router that ranks eligible candidates from experience.

The work board

Briefing runs turn your own connected tools into one ranked, read-only task list.

Prompt Studio

Edit every prompt section Bridge sends, with history, diffing, and a token-cost breakdown.

Integrated terminal

A real PTY per session, not a log tail.
