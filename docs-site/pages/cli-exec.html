bridge exec --json

The one-shot entry point for CI: hand it a prompt, get newline-delimited JSON back, no daemon babysitting required.

Example

Every line of output is a complete, independently-parseable JSON object — pipe it straight into jq or a test harness.

bash 
$ bridge exec --json "run the test suite and summarize failures"
{"type":"session_started","session_id":"ses_4c1a"}
{"type":"agent_message","text":"Running `bun run test`…"}
{"type":"result","status":"ok","duration_ms":48213}

Flags

FlagTypeDefaultDescription
--jsonbooleanfalseEmit newline-delimited JSON instead of formatted text
--harnessstringcodexWhich adapter to run: codex, claude, or opencode
--worktreepath—Run against an existing worktree instead of creating one
--timeoutduration10mKill the session if it runs past this

A second verb: scheduled learning runs

bridge learning run is the other CLI entry point — an external cron job wakes the adaptive-learning job on a schedule instead of a human waiting on a prompt. See Memory & adaptive learning for what that job actually does.

A session killed by --timeout does not clean up its worktree automatically — remove it yourself if you don't need it.
